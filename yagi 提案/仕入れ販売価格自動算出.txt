仕入れ・販売価格の自動算出ロジック

仕入れ時の「安全な上限額」と、販売時の「最大利益を狙う出品価格」を自動算出するPythonスクリプトの設計案です。

データ処理や配列計算に強いpandasやnumpyを利用することで、スクレイピングやAPIから取得した価格データを効率的に処理できます。

1. 算出ロジックの数式定義

スクリプトに落とし込む前に、計算の基準となる数式を定義します。

【仕入れ上限額 L_buy】

ヤフオク等の過去落札価格の第1四分位数（下位25%）を基準値P_baseとします。

P_base = ヤフオク落札価格の25パーセンタイル

その後、メルカリでの販売価格を予測するために、係数1.15を掛けて最低販売価格P_minを求めます。

P_min = P_base * 1.15

メルカリの販売手数料を10%とすると、実際に受け取れる金額は販売価格の90%です。

したがって、仕入れ上限額L_buyは以下の式で求められます。

L_buy = P_min * 0.90 - C_shipping - C_profit

ここで、

P_min
予測される最低販売価格

0.90
メルカリ販売手数料10%を差し引いた割合

C_shipping
送料

C_profit
最低限確保したい目標利益

です。

【出品推奨価格 P_start】

メルカリの現在の競合最安値をP_comp_min、過去のメルカリ最高成約価格をP_sold_maxとします。

まず、競合最安値を2%下回る価格と、過去最高成約価格を比較します。

P_target = max(P_comp_min * 0.98, P_sold_max)

そのうえで、値下げ交渉などを考慮して15%上乗せした価格を初期出品価格とします。

P_start = P_target * 1.15

2. Pythonスクリプト実装例

以下のコードは、APIやスクレイピングによって取得した価格データを配列として受け取り、計算結果を辞書型で返す関数です。

import numpy as np
import pandas as pd
def calculate_pricing_strategy(
    yahoo_sold,
    mercari_active,
    mercari_sold,
    shipping_cost,
    target_profit
):
    """
    仕入れ上限額と販売時の推奨出品価格を自動算出する関数
    """
    # ========================================
    # 1. 仕入れ上限額の計算
    # ========================================
    # ヤフオク落札価格の第1四分位数（25%点）を取得
    p_base = np.percentile(yahoo_sold, 25)
    # ヤフオク相場からメルカリ最低販売価格を予測
    p_min = p_base * 1.15
    # メルカリ手数料10%を考慮して仕入れ上限額を計算
    l_buy = (
        p_min * 0.90
        - shipping_cost
        - target_profit
    )
    # ========================================
    # 2. 出品推奨価格の計算
    # ========================================
    # メルカリ出品中商品の最安値
    p_comp_min = min(mercari_active) if mercari_active else 0
    # メルカリ過去成約商品の最高価格
    p_sold_max = max(mercari_sold) if mercari_sold else 0
    # 競合最安値の2%引きと過去最高成約価格を比較
    base_sell_target = max(
        p_comp_min * 0.98,
        p_sold_max
    )
    # 値下げ交渉等を考慮して15%上乗せ
    p_start = base_sell_target * 1.15
    # ========================================
    # 3. 結果を返す
    # ========================================
    return {
        "p_base": int(p_base),
        "p_min_estimated": int(p_min),
        "buy_limit": int(l_buy),
        "recommended_start_price": int(p_start)
    }
# ========================================
# 実行テスト
# ========================================
# APIやスクレイピング等で取得した仮想データ
yahoo_data = [
    4500,
    4800,
    5000,
    5500,
    7000
]
mercari_active_data = [
    6500,
    6800,
    7500
]
mercari_sold_data = [
    5800,
    6200,
    6800
]
result = calculate_pricing_strategy(
    yahoo_sold=yahoo_data,
    mercari_active=mercari_active_data,
    mercari_sold=mercari_sold_data,
    shipping_cost=500,
    target_profit=1500
)
print(
    f"【仕入れ判断】"
    f"上限額: {result['buy_limit']}円 "
    f"(予想最低販売額: {result['p_min_estimated']}円)"
)
print(
    f"【販売戦略】"
    f"初期出品価格: {result['recommended_start_price']}円"
)

今回の仮想データでは、ヤフオク落札価格は以下です。

第1四分位数は4800円となります。

となります。

メルカリ手数料10%、送料500円、目標利益1500円を考慮すると、

L_buy = 5520 * 0.90 - 500 - 1500

L_buy = 2968円

したがって、仕入れ上限額は、

仕入れ上限額 = 2968円

P_comp_min = 6500円

となります。

6370円と6800円を比較すると、6800円の方が高いため、

P_target = 6800円

となります。

したがって初期出品価格は、

P_start = 6800 * 1.15

となります。

4. システム運用に向けた設計ポイント

【1. データクレンジング】

実際のデータには、

・ジャンク品
・部品取り
・まとめ売り
・箱のみ
・動作未確認
・新品
・訳あり

など、通常の商品価格とは異なるデータが混ざります。

そのため、pandasを利用して商品タイトルや説明文を確認し、不要なデータを除外する処理を入れると精度を高められます。

例えば以下のようなフィルタリングが可能です。

df = df[
    ~df["title"].str.contains(
        "ジャンク|部品取り|まとめ売り",
        na=False
    )
]

また、IQR（四分位範囲）を利用して極端な外れ値を除外する方法もあります。

【2. バックエンドAPI化】

この価格計算ロジックをFastAPIやFlaskなどでAPI化すれば、以下のような仕組みに発展させることができます。

商品ページ
↓
価格データ取得
↓
Python API
↓
価格分析
↓
仕入れ上限額・推奨出品価格を計算
↓
画面上に結果を表示

例えば、

仕入れ上限: 2968円
推奨出品価格: 7820円
予想最低販売価格: 5520円

のように表示できます。

さらにブラウザ拡張機能と組み合わせれば、商品ページを開いた際に「この商品はいくらまでなら仕入れてよいか」を自動表示するシステムへ発展させることも可能です。
