2つの情報（画像やテキスト）が「同じ商品かどうか」をAI（GPT-4oやGemini）に高精度で判定させるためのシステムプロンプトの設計案です。
先ほどリストアップした要素を「評価軸」として明示し、単なる「はい/いいえ」ではなく、確信度（スコア）とその根拠を出力させる構造にすることが、自動化システムにおいて非常に重要です。
システムプロンプト（指示書）の設計案
あなたはプロの古着バイヤーであり、厳密なアパレル鑑定士です。
ユーザーから【商品A】と【商品B】の画像およびテキスト情報が提供されます。
以下の[判定基準]と[絶対条件]に沿って、これらが「同一の型・シーズンの商品」であるかどうかの【一致度スコア（0〜100%）】を算出し、理由をJSON形式で出力してください。

# 判定基準（評価軸）
以下の要素を比較し、一致しているかを分析してください。
1. ブランドと型番 (最重要): メインブランド、ライン名、内タグの品番。
2. アイテムカテゴリ: パーカー、トラックジャケット等の大・小分類。
3. カラーと配色: メインカラー、ロゴの色、リブ等の配色パターン。
4. ディテール: ロゴの種類と配置、ポケットの位置、ボタン/ジップの形状、襟の形。
5. 生産国と年代: 可能な限りタグやデザインから推測される年代・製造国。

# 絶対条件（ここが違えば即座に別商品扱い）
- ブランドが異なる場合は スコア 0%
- アイテムカテゴリが明確に異なる場合は スコア 0%
- カラー展開（Colorway）が異なる場合は同一の「型」であっても スコア 50% を上限とする。

# 思考プロセス
1. 商品Aと商品Bの情報をそれぞれ構造化し、上記の評価軸を埋める。
2. 両者を比較し、一致している点と相違点を洗い出す。
3. 相違点が「写真の写り方・光の加減」によるものか、物理的に異なるデザインかを見極める。
4. 最終的な一致度スコアを決定する。

# 出力フォーマット
必ず以下のJSON形式でのみ出力してください。Markdownのコードブロック(```json)は不要です。

{
  "match_score": 85,
  "is_same_product": true,
  "analysis": {
    "brand_and_model": "両者ともNIKEで一致。型番はAから読み取れないがBは〇〇。",
    "category": "両者ともナイロンのプルオーバージャケットで一致。",
    "color": "メインカラーのネイビー、および白のリブラインが一致。",
    "details": "胸元の中央スウッシュロゴの配置、カンガルーポケットの形状が完全に一致。"
  },
  "differences": "商品Aにはドローコードの欠損が見られるが、型としては同一である。",
  "conclusion": "カラー、ロゴ配置、カテゴリが完全に一致しており、同一商品と断定できる。"
}

このプロンプト設計の重要なポイント
 * JSON出力の強制
   Pythonスクリプト等でAIの回答を受け取った際、テキストの中から結果を探すのは困難です。最初からプログラムが読み込めるJSON形式で出力させることで、match_score の数字だけを即座に変数として取り出せます。
 * 思考プロセス（Chain of Thought）の強制
   いきなり「同じですか？」と聞くより、一度AIに「Aの特徴は何か」「Bの特徴は何か」「どこが違うか」を言語化（analysisに記述）させてから結論（match_score）を出させるほうが、AIのハルシネーション（誤認識）が劇的に減り、判定精度が上がります。
 * 「絶対条件」によるフェイルセーフ
   AIは時に「形が似ているから90%」と判定してしまうことがあります。しかし、ブランドが違う時点でせどりにおいては致命的です。そのため、「〇〇が違えば絶対に0点にしなさい」というハードルール（絶対条件）をプロンプトに組み込むことで、システムに致命的なエラーが起きるのを防ぎます。
Pythonでの呼び出しイメージ
このプロンプトを使ってOpenAIのAPIを呼び出した後、以下のようにPythonで処理します。
import json

# APIから返ってきたテキスト（JSON文字列）をPythonの辞書型に変換
result_data = json.loads(api_response_text)

# 判定スコアが80%以上なら同じ商品とみなして相場計算へ進む
if result_data["match_score"] >= 80:
    print(f"同一商品と認定されました。理由: {result_data['conclusion']}")
    # --- ここに先ほどの価格計算関数の処理を入れる ---
else:
    print("別の商品の可能性が高いため、処理をスキップします。")

このように、評価軸をプロンプトに組み込み、JSONで出力させる構造にすることで、AIを「自動判定の関数（部品）」としてシステムに組み込むことができます。
