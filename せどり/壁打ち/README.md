# sedori 自動化プロジェクト

ブランド古着せどりの作業を自動化するためのプロジェクトです。

## 目標
- 仕入れ先（まずは KINDAL）の新着商品を自動で監視する
- 取扱ブランドの新着が出たら Discord に通知する
- 通知はスマホで受け取る
